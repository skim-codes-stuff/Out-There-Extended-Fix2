# Out There demo

This version is a deterministic demonstration. It does not call Groq, Google
Chat, or any AI service.

## Run the fake conversation

1. Run `npm start`.
2. Open `http://localhost:3000` to view the fictional conversation between
   Dimitry and You.
3. Open the extension and select **Summarize Demo Conversation**.
4. Open **Contacts** or **Conversations** to see the seeded keypoints.

**Contacts** are person-level profiles covering observed personality and
interaction style, likes and preferences, dislikes or constraints, inside
jokes, and possible meanings of phrases. **Conversations** stay specific to
the moment, recording context, tone, subtext, agreements, and the transcript.

The sample profiles and tone/subtext notes are illustrative interpretations
based on the fictional demo, not claims about what either person intended.
Demo data is saved in extension storage; **Clear Saved Demo Data** removes the
saved contacts and conversations.
